# Frontier Echo — Windows Alpha

Explore, trade, build and defend your place in the galaxy.

## Download and play

**[Download Frontier Echo Setup](https://github.com/Dalarian1/Frontier-Echo-Downloads/releases/latest/download/FrontierEchoSetup.exe)**

1. Run **FrontierEchoSetup.exe** and choose **Install**.
2. Wait for the first game download (about 425 MB).
3. Use the **Frontier Echo** desktop icon to play. It checks for updates automatically.

Windows 10/11, 64-bit. No GitHub account or administrator access is needed.
The installer is not Windows code-signed yet, so Windows may show an unknown-publisher warning. Only use the download linked from this repository; if your computer blocks it, ask your host for help rather than disabling security software.

For multiplayer, ask your host for your **personal invitation file**. Choose **Play** and select it once. The game remembers its location; future Play clicks connect directly into flight. Keep the file where you saved it, or use **Connection** to select its new location. Important "While you were away" reports appear in-game, not on a separate connection desk. Keep your invitation private: do not post it in chat, in this repository, or in a bug report. Downloading the game does not automatically grant access to a private server.

## Updates and saves

Close the game and reopen its desktop icon to receive a published update. An update is downloaded and verified before the launcher selects it. Updates do not replace your saved games. Hosts coordinate server updates separately; if a server reports a version mismatch, contact its host.

This is an early testing build. Features, balance and compatibility can change. Report problems to your test host, without attaching invitation files or server keys.

## About this repository

This repository distributes game builds only. It is not the game's source repository. The `.bin` release assets and `channel.json` are used by the installer/updater; players only need **FrontierEchoSetup.exe**. GitHub's automatic "Source code" downloads contain this download page, not the game.

The game uses Godot; its license and third-party notices are included in the installed game as `GODOT-LICENSES.txt`.
